Previous versions of jServer:  
  
jServer4.1, based on Jetty 11.0.26: [https://www.b4x.com/b4j/files/jServer4.zip](https://www.b4x.com/b4j/files/jServer3.zip). Requires Java 11+. Instructions: <https://www.b4x.com/android/forum/threads/jserver-v4-0-based-on-jetty-11.140437/#content>.  
jServer3, based on Jetty 9.4: <https://www.b4x.com/b4j/files/jServer3.zip>
