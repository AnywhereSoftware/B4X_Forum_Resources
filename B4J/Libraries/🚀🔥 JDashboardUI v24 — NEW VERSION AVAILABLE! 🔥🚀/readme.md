🔐 NEW JLicenseManager  
━━━━━━━━━━━━━━━━━━━━  
  
One of the biggest additions in this version is **JLicenseManager**.  
  
This new module allows developers to integrate an application licensing system directly into B4J applications.  
  
Its capabilities include:  
  
✅ Hardware-bound licenses using HWID  
✅ License expiration dates  
✅ Different license levels/types  
✅ Trial mode / configurable trial periods  
✅ License validation  
✅ Local license information storage  
✅ Protection against certain system clock/date changes  
✅ Modern activation dialog  
✅ Multiple visual styles  
✅ Customizable text for localization  
  
This makes it possible to add an activation system to an application without having to build the entire licensing workflow from scratch.  
  
JLicenseManager is designed to integrate directly into applications created with JDashboardUI.

📊 JTABLEVIEW CONTINUES TO EVOLVE  
━━━━━━━━━━━━━━━━━━━━  
  
**JTableView** also receives major improvements.  
  
The goal is to progressively turn it into an advanced Data Grid for B4J applications while keeping normal table behavior and adding selected spreadsheet-style features.  
  
Available features include:  
  
✅ Editable cells  
✅ Formulas  
✅ Cell references  
✅ Formula bar  
✅ Fill Handle for extending values and formulas  
✅ Filters  
✅ Hide and restore columns  
✅ Create and delete rows  
✅ Create and delete columns  
✅ Move rows and columns  
✅ Different data types  
✅ Controls inside cells  
✅ Header customization  
✅ Individual column width control  
✅ Row height control  
✅ Multilanguage support  
✅ Multiple visual styles  
  
The objective is not to recreate Excel.  
  
The objective is to provide B4J developers with a significantly more powerful Data Grid for business, administrative and desktop applications.

⚙️ HOW TO INSTALL JDASHBOARDUI v24  
━━━━━━━━━━━━━━━━━━━━  
  
Installation is simple.  
  
1️⃣ Download the JDashboardUI package from B4XApp.com.  
  
2️⃣ Extract the downloaded archive.  
  
3️⃣ Inside the package you will find the:  
  
libraries  
  
folder.  
  
4️⃣ Copy the required files from this folder to the **Additional Libraries** directory configured in B4J.  
  
You can check the configured path from:  
  
Tools → Configure Paths → Additional Libraries  
  
5️⃣ If you already have an older version of JDashboardUI installed, replace the previous files with the corresponding files from the new version.  
  
⚠️ It is recommended not to keep multiple copies of the same library with different names.  
  
For example, avoid files such as:  
  
jdashboardUI.b4xlib  
jdashboardUI (1).b4xlib  
jdashboardUI\_old.b4xlib  
  
because B4J may end up loading the wrong version.  
  
6️⃣ Restart B4J or refresh the libraries list.  
  
7️⃣ Open your project and select **jdashboardUI** from the Libraries Manager.  
  
✅ The example projects do NOT need to be copied into Additional Libraries.  
  
You can keep them anywhere on your computer and open their .b4j files directly from B4J.
