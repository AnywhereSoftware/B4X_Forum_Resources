### 🚀 New tools are coming very soon to jDashboardUI! by fernando1987
### 11/13/2026
[B4X Forum - B4J - Libraries](https://www.b4x.com/android/forum/threads/172546/)

Here’s a sneak peek at two upcoming additions:  
  
✨ **JPropertyGrid**  
A property inspector for your applications, featuring categories, tabs, search, and dedicated editors for text, numbers, options, colors, dates, files, and more. Ideal for visual designers, configuration panels, and tools that need an organized interface for editing object properties.  
  
![](https://www.b4x.com/android/forum/attachments/174810) ![](https://www.b4x.com/android/forum/attachments/174811)  
  
📝 **Integrated log panel in MonacoEditorView**  
Display debugging messages, process output, and build logs directly within the editor interface. The panel supports copying and clearing its contents, pinning, expanding, and hiding—making it easier to follow what’s happening while working with your code.  
  
![](https://www.b4x.com/android/forum/attachments/174812)  
  
😉 **And here’s a little hint…** Combine a code editor, a project explorer, a property inspector, and a log panel, then add a visual designer built with HTML/JavaScript inside a WebView… and you already have several of the building blocks needed to create your own IDE.  
  
**jDashboardUI will keep putting these tools into its users’ hands. What you build with them is up to your imagination.** 🛠️  
  
Stay tuned—these additions are coming in a very near update!
