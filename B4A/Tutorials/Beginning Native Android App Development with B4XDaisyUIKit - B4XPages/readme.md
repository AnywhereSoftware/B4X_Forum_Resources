🚀 Getting Started & Setup  

1. **Install B4A & Dependencies:** Ensure you have **B4A** installed along with the required **Open JDK**, **Android SDK**, and resources set up. Don't forget to enable **USB Debugging** on your test device.
2. **Download Library Files:** Download the **B4XDaisyUIKit** library assets from GitHub or the Google Drive link.
3. **Copy to Additional Libraries:** Copy the downloaded library files and the **B4X Template** into your B4A Additional Libraries folder.
4. **Create a New Project:** Open B4A, navigate to **File ➔ Create New Project**, and select the **B4XDaisyUIKit App** template. Give your project a name (e.g., My New Android App).

---

  
🛠️ How It Works (B4XPages Architecture)  
  
The template automatically sets up a clean **B4XPages** project structure. When the application launches, a smooth splash screen with a **spinning loading canvas** displays while all background pages initialize in their respective class modules.  
  
1. Programmatic Layout Example  
2. Interactive Logic & SweetAlerts  
3. UX Features Included  

- **Smart Keyboard Handling:** Input fields automatically shift upward when the soft keyboard appears so fields are never obscured.
- **Graceful App Closure:** Captures the CloseRequest event to show a confirmation dialog ("*Are you sure that you want to close the application?*") before calling ExitApplication.

🎨 Design via the Abstract Designer  
  
If you prefer visual layout design over code:  

1. Open the **Abstract Designer** in B4A.
2. Add **Custom Views** from the list (e.g., B4XDaisyButton).
3. Adjust visual properties in the properties tab (margins, text, variant styles like solid, etc.).
4. Right-click ➔ **Generate Members** to automatically declare views and click event handlers.
