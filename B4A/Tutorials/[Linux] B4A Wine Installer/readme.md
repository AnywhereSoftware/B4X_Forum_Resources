[HEADING=1]🚀 How to use[/HEADING]  
Just 3 lines of commands (You can copy and paste in one go).  

```B4X
wget https://raw.githubusercontent.com/pyhoon/b4a-wine-installer/main/install_b4a_wine.sh  
chmod +x install_b4a_wine.sh  
./install_b4a_wine.sh
```
