### GoogleMapsExtras by warwound
### 10/18/2026
[B4X Forum - B4A - Libraries](https://www.b4x.com/android/forum/threads/26277/)

**GoogleMapsExtras is an ongoing project to implement more of the Google Maps Android v2 classes in Basic4Android.**  
  
Currently the library allows you to create these objects:  

- [BitmapDescriptor](https://developers.google.com/maps/documentation/android/reference/com/google/android/gms/maps/model/BitmapDescriptor)
- [BitmapDescriptorFactory](https://developers.google.com/maps/documentation/android/reference/com/google/android/gms/maps/model/BitmapDescriptorFactory)
- [Circle](https://developers.google.com/maps/documentation/android/reference/com/google/android/gms/maps/model/Circle)
- [CircleOptions](https://developers.google.com/maps/documentation/android/reference/com/google/android/gms/maps/model/CircleOptions)
- [GroundOverlay](https://developers.google.com/maps/documentation/android/reference/com/google/android/gms/maps/model/GroundOverlay)
- [InfoWindowAdapter](https://developers.google.com/maps/documentation/android/reference/com/google/android/gms/maps/GoogleMap.InfoWindowAdapter)
- [MarkerOptions](https://developers.google.com/maps/documentation/android/reference/com/google/android/gms/maps/model/MarkerOptions)
- [Point](http://developer.android.com/reference/android/graphics/Point.html)
- [Projection](https://developers.google.com/maps/documentation/android/reference/com/google/android/gms/maps/Projection)
- [OnInfoWindowClickListener](https://developers.google.com/maps/documentation/android/reference/com/google/android/gms/maps/GoogleMap.OnInfoWindowClickListener)
- [OnMarkerDragListener](https://developers.google.com/maps/documentation/android/reference/com/google/android/gms/maps/GoogleMap.OnMarkerDragListener)
- [OnMyLocationChangeListener](https://developers.google.com/maps/documentation/android/reference/com/google/android/gms/maps/GoogleMap.OnMyLocationChangeListener)
- [Polygon](https://developers.google.com/maps/documentation/android/reference/com/google/android/gms/maps/model/Polygon)
- [TileOverlay](https://developers.google.com/maps/documentation/android/reference/com/google/android/gms/maps/model/TileOverlay)
- [VisibleRegion](https://developers.google.com/maps/documentation/android/reference/com/google/android/gms/maps/model/VisibleRegion)

  
Tutorials for each object will be uploaded to the [Google Maps Android v2 tutorial](http://www.b4x.com/forum/basic4android-getting-started-tutorials/24415-google-maps-android-v2-tutorial-6.html#post152010) thread.
