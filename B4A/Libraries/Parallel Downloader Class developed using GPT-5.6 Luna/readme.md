Hi everyone.   
I have developed a useful module using **GPT-5.6 Luna.** It was a good experience, and I wonder how well it knows B4X.  
Downloader.bas is a shared B4X class for downloading multiple files from a common base URL. It supports **B4A** and **B4i**.  

- Downloads files in parallel.
- Limits parallel jobs with MaxConcurrentDownloads.
- Retries failed files in complete rounds.
- Saves files to DownloadFolder.
- Supports both Wait For and No Wait modes.
- Supports optional callbacks in either mode.

See the attached .html manual for more information.
