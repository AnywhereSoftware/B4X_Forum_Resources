### cSliderMulti – A multi-column slider by Grinaute
### 07/21/2026
[B4X Forum - B4A - Libraries](https://www.b4x.com/android/forum/threads/171590/)

To dynamically change the number of columns in a B4A CustomListView, I needed a specific slider component that I couldn’t find anywhere on the forums.  
  
I decided to create my own solution and share it with the B4X community as a B4XLib.  
  
Since I mainly work with B4A and don’t use B4J or B4I, I haven’t tested its compatibility with those platforms. If you are interested, feel free to adapt, improve, or extend it to better suit your needs.  
  
I hope it can be useful to others!  
  
**v1.10 - Slider component update**  
  
Following the first release of this custom slider component, I have added several improvements and reorganized the class to make it easier to understand, maintain, and extend.  
  
The main improvements are:  
  
- Added support for vertical slider orientation.  
- Added the ability to reverse the direction of the vertical slider.  
- Improved the management of item positions and selection.  
- Better separation between internal calculations, drawing, and user interaction handling.  
  
I have also reorganized the class using #Region sections to clearly separate the different parts of the component. This new structure makes the code easier to navigate and should help anyone who wants to modify or extend the component.  
  
The goal remains the same: to provide a simple, reusable, and adaptable slider component for B4A projects.  
  
Feel free to use it, adapt it, or improve it according to your needs. Feedback and suggestions are welcome!
