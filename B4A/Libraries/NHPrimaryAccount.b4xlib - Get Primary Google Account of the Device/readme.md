Greetings to everyone,  
  
With this library you can get the primary google account of the device. All you have to do is:  
  

```B4X
Dim primac As PrimaryAccount  
primac.Instructions
```

  
  
While writting the second line you will be presented with a code which you will copy in order to use the library and check it easily. All the necessary steps on what you need to add to the manifest and RuntimePermissions are in there.
